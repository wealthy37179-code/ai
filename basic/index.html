📊 05. 데이터 분석

pandas를 활용한 데이터 분석

CSV는 표 형태의 데이터를 쉼표로 구분해 저장하는 파일이며, Python 데이터 분석에서 가장 기본적으로 사용하는 데이터 형식 중 하나입니다. 이 장에서는 pandas 라이브러리를 활용하여 데이터를 다루고 분석하는 방법을 학습합니다.

📂 [0차시] CSV 파일과 경로 이해하기

Comma-Separated Values
데이터를 쉼표(,)로 구분하여 저장하는 텍스트 파일이며, 확장자는 .csv를 사용합니다. 쉽게 말하면 엑셀의 표를 아주 단순한 텍스트 형태로 저장한 파일이라고 생각하면 됩니다.

1. CSV 파일은 어떻게 생겼을까요?
• 텍스트로 보면: 이름, 국어, 수학 / 민준,85,90 / 서연,92,88 / 지우, 78,95
• 표로 보면: 한 줄 = 하나의 행(row), 쉼표(,) = 열(column)을 구분. 모든 행은 같은 구조를 가지는 것이 기본.

2. CSV를 왜 사용할까요?
✓ 용량이 작고 구조가 단순함
✓ Python pandas로 쉽게 불러올 수 있음
✓ Excel-Google Sheets에서 열 수 있음
✓ 프로그램 간 데이터 전달에 유용함

3. CSV 파일 만드는 방법
① 엑셀 ② 구글 시트 ③ 메모장
데이터 입력 → 다른 이름으로 저장 → CSV 형식 선택 / 쉼표로 구분된 값(.csv) 선택 → 파일명을 data.csv처럼 저장

4. 한글이 깨진다면?
TIP: 한글 깨짐을 방지하려면 UTF-8 인코딩을 사용하는 것을 권장합니다.
Python 예시: df = pd.read_csv("data.csv", encoding="utf-8")

5. 데이터 분석에서의 흐름
CSV 파일 → DataFrame → 전처리·분석·시각화

파일 경로(path)란?
파이썬이 CSV 파일 읽을 때 파일이 어디에 있는지 알려주는 주소입니다. 쉽게 말하면 파일을 찾아가는 길이라고 생각하면 됩니다.
1. 절대 경로와 상대 경로는 무엇이 다를까요?
구분절대 경로상대 경로
기준컴퓨터 안에서 파일이 있는 전체 위치현재 작업 중인 폴더를 기준으로 한 위치
예C:/Users/user/Downloads/data.csvdata.csv 또는 data/data.csv
특징현재 위치와 상관없이 파일 위치가 명확함짧고 간단하며 프로젝트 폴더를 옮기기 편리함

2. 폴더 구조로 보면 더 쉬워요
① CSV가 같은 폴더에 있을 때: pd.read_csv("score.csv")
② CSV가 data 폴더 안에 있을 때: pd.read_csv("data/score.csv")

3. 꼭 알아둘 경로 기호
• ./ 현재 폴더
• ../ 한 단계 위 폴더
• / 폴더와 파일 구분

4. CSV 파일을 못 찾는다면?
TIP: FileNotFoundError가 나오면 먼저 파이썬이 현재 어느 폴더를 기준으로 파일을 찾는지 확인합니다. (import os, print(os.getcwd())) 그 다음 CSV 파일 이름과 폴더 위치가 경로와 맞는지 확인합니다.

5. 한 문장으로 기억하기
• 절대 경로: 파일의 전체 주소를 적는 방법
• 상대 경로: 지금 있는 위치에서 파일까지 가는 길을 적는 방법
경로를 이해하면 pandas의 read_csv()로 CSV 파일을 훨씬 쉽게 불러올 수 있습니다.

📊 [1차시] Series와 DataFrame 만들기

핵심 개념 설명: pandas는 행과 열로 구성된 표 데이터를 다루는 파이썬 라이브러리입니다. Series는 이름표가 있는 1차원 자료이고 DataFrame은 여러 열로 이루어진 표입니다. 리스트와 딕셔너리로 작은 설문 표를 직접 만들어 두 구조를 비교합니다. 실행 환경에 pandas가 없다면 터미널에서 python -m pip install pandas matplotlib를 한 번 실행합니다.

PYTHON전체 실습 코드
import pandas as pd
scores = pd.Series([82, 75, 90], name="score")
data = {
    "brand": ["세종우유", "한솔제과", "세종푸드"],
    "score": [82, 75, 90],
    "responses": [20, 18, 25]
}
df = pd.DataFrame(data)
print("한 열의 자료:", scores)
print("전체 표:", df)
print("행과 열의 개수:", df.shape)
🔍 코드 톺아보기
• import pandas as pd: pandas를 pd라는 짧은 이름으로 사용합니다.
• pd.DataFrame(data): 딕셔너리의 키는 열 이름이 되고 각 리스트는 열의 값이 됩니다.
• df.shape: (3, 3)은 3행 3열이라는 뜻입니다.

💾 [2차시] CSV 파일 저장과 불러오기

핵심 개념 설명: CSV는 쉼표로 열을 구분하는 텍스트 파일 형식입니다. pandas의 read_csv로 파일을 표로 읽고 to_csv로 분석 결과를 저장할 수 있습니다.

PYTHON전체 실습 코드
import pandas as pd
sample = pd.DataFrame({
    "brand": ["세종우유", "한솔제과", "세종푸드"],
    "score": [82, 75, 90]
})
file_name = "lesson02_survey.csv"
sample.to_csv(file_name, index=False, encoding="utf-8")
df = pd.read_csv(file_name, encoding="utf-8")
print("읽어 온 자료:", df.head())
print("열 이름:", df.columns)
print("행 수:", len(df))
🔍 코드 톺아보기
• to_csv와 index=False: 표를 파일로 저장하면서 행 인덱스를 별도 열로 쓰지 않게 합니다.
• encoding="utf-8" : 한글 CSV의 인코딩을 지정합니다.

🔎 [3차시] 자료 구조와 기초 통계 확인

핵심 개념 설명: 분석을 시작하기 전에는 행과 열의 크기, 자료형, 누락값 유무를 먼저 살펴야 합니다. info는 열별 자료형과 값이 있는 개수를 보여주고 describe는 숫자 열의 기초 통계를 요약합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "brand": ["A", "B", "C", "D"],
    "score": [80, 90, None, 70],
    "responses": [20, 30, 10, 20]
})
print("자료 일부:", df.head())
print("크기:", df.shape)
df.info()
print("숫자 열 통계:", df.describe())
print("열별 누락값 수:", df.isna().sum())
🔍 코드 톺아보기
• df.info(): 자료형과 Non-Null Count를 확인합니다.
• describe(): count, mean, std, min, 사분위수, max를 보여줍니다.
• isna().sum(): 누락 여부를 확인하고 합산합니다.

🎯 [4차시] 열 선택과 loc iloc 이해하기

핵심 개념 설명: DataFrame에서 필요한 부분을 고를 때는 이름표로 선택하는 loc와 정수 위치로 선택하는 iloc를 구분해야 합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "brand": ["세종우유", "한솔제과", "세종푸드"],
    "score": [82, 75, 90],
    "responses": [20, 18, 25]
}, index=["a", "b", "c"])
print(df["score"])
print(df[["brand", "score"]])
print("이름표로 선택:")
print(df.loc["a":"b", ["brand", "score"]])
print("위치로 선택:")
print(df.iloc[0:2, 0:2])
🔍 코드 톺아보기
• df["score"]는 Series이며, df[["brand", "score"]]는 DataFrame입니다.
• loc["a":"b"]는 이름표 범위의 끝을 포함합니다.
• iloc[0:2, 0:2]는 정수 위치 기반으로 행과 열을 선택합니다.

✂️ [5차시] 조건 필터링과 정렬

핵심 개념 설명: 분석 질문을 조건식으로 바꾸면 관심 있는 행만 추출할 수 있습니다. pandas의 여러 조건은 &로 결합하고 각 조건을 괄호로 감쌉니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "brand": ["A", "B", "C", "D"],
    "score": [85, 72, 90, 88],
    "responses": [25, 30, 12, 22]
})
condition = (df["score"] >= 80) & (df["responses"] >= 20)
selected = df.loc[condition, ["brand", "score", "responses"]]
ranked = selected.sort_values("score", ascending=False)
print("조건에 맞는 행:", selected)
print("선택한 행수:", len(selected))
🔍 코드 톺아보기
• & 연산자를 사용하여 여러 조건을 모두 만족하는 행을 필터링합니다.
• sort_values를 사용하여 특정 열 기준 내림차순 또는 오름차순 정렬을 수행합니다.

🧹 [6차시] 자료형 변환과 결측·중복 처리

핵심 개념 설명: 실제 자료에는 숫자로 변환할 수 없는 값, 누락값, 중복 행이 섞여 있을 수 있습니다. 숫자로 변환할 수 없는 값을 결측으로 바꾸고 중복을 제거한 뒤 분석 가능한 행을 선택합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "id": [1, 2, 2, 3, 4],
    "score": ["80", "90", "90", "미응답", None]
})
clean = df.drop_duplicates().copy()
clean["score"] = pd.to_numeric(clean["score"], errors="coerce")
print("결측값 수:", clean["score"].isna().sum())
valid = clean.dropna(subset=["score"]).copy()
filled = clean["score"].fillna(clean["score"].mean())
print("평균으로 대체한 경우:", filled.tolist())
print("원본 행수:", len(df), "유효 행수:", len(valid))
print("유효 점수 평균:", valid["score"].mean())
🔍 코드 톺아보기
• drop_duplicates를 통해 중복 행을 제거합니다.
• pd.to_numeric(..., errors="coerce")를 사용하여 잘못된 문자열을 NaN(결측값)으로 변환합니다.

📊 [7차시] 반별 평균을 구하는 groupby

핵심 개념 설명: 여러 행을 같은 기준으로 묶어 비교할 때 groupby를 사용합니다. 반별 점수 평균과 학생 수를 계산하여 그룹별 특징을 빠르게 파악합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "class": ["1반", "1반", "2반", "2반", "3반", "3반"],
    "name": ["민서", "지우", "서준", "하린", "도윤", "서연"],
    "score": [88, 95, 76, 84, 91, 79]
})
summary = df.groupby("class")["score"].mean().round(1)
print(summary)
print('='*10)
summary2 = df.groupby("class")["score"].agg(["count", "mean"])
summary2["mean"] = summary2["mean"].round(1)
print(summary2)
🔍 코드 톺아보기
• groupby("class")로 그룹을 묶고 mean()이나 agg()를 통해 통계량을 산출합니다.

📉 [8차시] 여러 통계를 한 번에 계산하는 agg

핵심 개념 설명: agg를 이용해 평균, 최솟값, 최댓값을 동시에 계산하고 그룹별 차이를 비교합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "category": ["음료", "음료", "음료", "간식", "간식", "간식"],
    "sales": [120, 150, 90, 80, 110, 140]
})
result = df.groupby("category")["sales"].agg(
    count="count",
    average="mean",
    minimum="min",
    maximum="max"
)
result["average"] = result["average"].round(1)
print(result)
🔍 코드 톺아보기
• agg() 내에서 새로운 열 이름을 지정하여 여러 집계 함수를 동시에 적용할 수 있습니다.

📋 [9차시] 두 기준을 표로 바꾸는 pivot_table

핵심 개념 설명: 행과 열 두 가지 기준으로 데이터를 요약하려면 pivot_table을 사용합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "region": ["서울", "서울", "서울", "세종", "세종", "세종"],
    "time": ["아침", "점심", "저녁", "아침", "점심", "저녁"],
    "users": [35, 52, 41, 28, 47, 33]
})
pivot = pd.pivot_table(
    df, values="users", index="region", columns="time",
    aggfunc="mean", fill_value=0
)
print(pivot)
print("서울 점심 이용자:", pivot.loc["서울", "점심"])
🔍 코드 톺아보기
• index, columns, values를 지정하여 다차원 교차 표 형태의 요약 데이터를 생성합니다.

🔤 [10차시] 문자열 데이터를 정제하는 str 기능

핵심 개념 설명: pandas의 str 기능으로 공백 제거, 대소문자 변환, 값 대체 등을 수행하여 문자열 데이터를 정제합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "region": [" 서울", "서울", "세종시", "세종시", "대전"],
    "product": ["Milk", "milk", "SNACK", "Snack", "milk"]
})
clean = df.copy()
print('원본 region:', clean["region"].tolist())
clean["region"] = clean["region"].str.strip()
clean["region"] = clean["region"].replace({"세종시": "세종"})
clean["product"] = clean["product"].str.strip().str.lower()
print(clean)
print(clean["product"].value_counts())
🔍 코드 톺아보기
• str.strip(), str.lower() 등을 활용하여 일관된 형태로 문자열을 정제합니다.

📈 [11차시] 빈도와 비율을 함께 보는 value_counts

핵심 개념 설명: value_counts로 빈도를 계산하고 normalize=True를 사용하면 전체에서 차지하는 비율까지 확인할 수 있습니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "choice": ["A", "B", "A", "C", "A", "B", "B", "A", "C", "A"]
})
counts = df["choice"].value_counts()
ratios = df["choice"].value_counts(normalize=True).mul(100).round(1)
report = pd.DataFrame({"count": counts, "ratio(%)": ratios})
print(report)
🔍 코드 톺아보기
• normalize=True를 통해 비율 백분율 데이터를 쉽게 생성합니다.

📅 [12차시] 날짜 데이터를 변환하고 월별로 분석하기

핵심 개념 설명: 날짜형 데이터로 변환 후 dt 접근자를 사용하여 월, 요일별 분석을 수행합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "date": ["2026-09-01", "2026-09-03", "2026-10-01", "2026-10-05"],
    "visitors": [120, 135, 150, 145]
})
df["date"] = pd.to_datetime(df["date"])
df["month"] = df["date"].dt.month
df["day"] = df["date"].dt.day
df["weekday"] = df["date"].dt.day_name()
monthly = df.groupby("month")["visitors"].mean().round(1)
print(df)
print(monthly)
🔍 코드 톺아보기
• pd.to_datetime()과 dt 속성을 활용하여 시계열 데이터를 다룹니다.

🔗 [13차시] 두 표를 연결하는 merge

핵심 개념 설명: 공통된 키(Key)를 기준으로 두 개의 DataFrame을 결합합니다.

PYTHON전체 실습 코드
import pandas as pd
students = pd.DataFrame({
    "id": [1, 2, 3, 4],
    "name": ["민서", "지우", "서준", "하린"],
    "class": ["1반", "1반", "2반", "2반"]
})
scores = pd.DataFrame({
    "id": [1, 2, 3, 4],
    "score": [88, 95, 76, 84]
})
merged = pd.merge(students, scores, on="id", how="inner")
merged["pass"] = merged["score"] >= 80
print(merged)
print("통과 인원:", merged["pass"].sum())
🔍 코드 톺아보기
• pd.merge()를 사용하여 두 표를 공통 키 기준으로 연결합니다.

⚡ [14차시] 함수와 apply로 파생 열 만들기

핵심 개념 설명: 사용자 정의 함수를 apply()와 결합하여 새로운 열을 생성합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "name": ["민서", "지우", "서준", "하린"],
    "score": [95, 82, 74, 61]
})
def grade(score):
    if score >= 90: return "A"
    if score >= 80: return "B"
    if score >= 70: return "C"
    return "D"
df["grade"] = df["score"].apply(grade)
print(df)

🏆 [15차시] 종합 프로젝트: 매점 판매 데이터 분석

핵심 개념 설명: 전처리, 파생 열 생성, 그룹화, 정렬, 파일 저장까지의 전체 데이터 분석 흐름을 실습합니다.

PYTHON전체 실습 코드
import pandas as pd
df = pd.DataFrame({
    "product": ["우유", "과자", "우유", "음료", "과자", "우유"],
    "price": [1500, 1200, 1500, 1800, 1200, 1500],
    "qty": [10, 15, "미입력", 8, 12, 20]
})
clean = df.copy()
clean["qty"] = pd.to_numeric(clean["qty"], errors="coerce")
clean = clean.dropna(subset=["qty"]).copy()
clean["sales"] = clean["price"] * clean["qty"]

report = clean.groupby("product").agg(
    total_qty=("qty", "sum"),
    total_sales=("sales", "sum")
).sort_values("total_sales", ascending=False)

print(report)
print("매출 1위 상품:", report.index[0])
report.to_csv("project.csv", encoding="cp949")
